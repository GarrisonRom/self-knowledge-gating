# Data layout

数据按生命周期分层：

1. `raw/`：原始下载或人工收集的数据，只保存来源清单和哈希，不提交真实内容。
2. `interim/`：清洗、去重、切分和标注中间产物。
3. `processed/`：实验可直接读取的版本化数据、索引和 manifest。
4. `external/`：外部语料、基准或服务导出的数据，必须记录许可和版本。

每个数据版本至少记录来源、许可、获取时间、处理脚本版本、样本数量和校验哈希。问答样本的字段契约见 `docs/annotation_schema.md`。

首个领域实例是材料科学：使用 Materials Project 的版本化记录生成常见属性、长尾、无答案 canary、时间漂移和受控冲突切片。原始记录与向量索引仍保持在本地或对象存储中，仓库只提交 manifest、字段映射和可复现的生成配置。
