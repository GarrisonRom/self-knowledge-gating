# Source package boundary

后续实现按以下边界拆分，保持信号、策略和外部服务可替换：

- `schemas.py`：问题、证据、信号和决策的内部数据契约。
- `signals.py`：自我知识、可回答性、歧义和证据充分性估计。
- `calibration.py`：校准器、可靠性指标和阈值选择。
- `retrieval/`：检索器接口、证据标准化和快照。
- `conflict/`：参数记忆与证据的冲突检测、裁决和审计记录。
- `policy.py`：四动作门控策略。
- `evaluation/`：选择性风险、成本和分层评测。

这些模块目前只定义设计边界，尚未绑定具体模型或向量数据库。
